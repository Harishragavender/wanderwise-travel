## 📖 Overview

A premium travel planning platform for discovering destinations, estimating travel budgets, building itineraries, and packing checklists.

This project was built as part of the **Web Technology Portfolio** series to demonstrate client-side web application development, interactive user interfaces, clean CSS architecture, and modern UX patterns.

---

## ✨ Key Features

- **Destination Discovery**: Curated destination cards across Europe, Asia, Americas, and tropical getaways.
- **Itinerary Builder**: Day-by-day activity planning with estimated duration and cost allocations.
- **Budget Estimator**: Live trip cost calculator for flights, accommodations, dining, and activities.
- **Interactive Packing List**: Dynamic checklist to track essential travel documents, gear, and clothing.
- **Traveler Reviews & Guides**: Tips, best travel seasons, and local customs for each location.

## 🚀 Getting Started & Local Setup

### 1. Clone the repository
`ash
git clone https://github.com/Harishragavender/wanderwise-travel.git
cd wanderwise-travel
`

### 2. Run locally
Since this is a client-side web application with zero external runtime dependencies, you can run it immediately:

- **Option A (Direct)**: Double-click `index.html` to open it directly in any modern web browser (Chrome, Edge, Firefox, Safari).
- **Option B (Live Server)**: Open the folder in VS Code, right-click `index.html` and choose **"Open with Live Server"**.
- **Option C (Python local server)**:
  `ash
  python -m http.server 8000
  `
  Then visit http://localhost:8000.
